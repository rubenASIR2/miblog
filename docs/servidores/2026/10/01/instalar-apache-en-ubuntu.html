Instalar apache en Ubuntu Server

Oct 1, 2026

En esta práctica instalamos el servidor web Apache y comprobamos que responde en el puerto 80.

Instalación

sudo apt update
sudo apt install apache2
sudo systemctl enable --now apache2

Comprobación

systemctl status apache2
curl -I http://localhost

Si todo va bien, el navegador mostrará la página It works! (insertar imágenes apache-it-works.png, apache-logo.png).
